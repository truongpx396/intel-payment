# .specify

This repository follows a spec-driven workflow: specification and contracts precede code, and a
contract change lands with the code that implements it.

- `memory/constitution.md` — the principles every change is checked against.
- `../specs/001-metering-billing-core/` — the active feature: spec, plan, data model, decisions,
  tasks, and the normative contracts.
